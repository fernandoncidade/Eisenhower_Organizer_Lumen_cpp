5. FEATURES AND DATA
   - The Software stores tasks locally in the tasks.json file in the user's persistent path (e.g., AppData). There is no automatic transmission of data to external servers.
   - The Software offers export (XLSX, PDF, JSON) and import (XLSX, PDF). Exported files are saved in the location chosen by the user.
   - Accessibility and compliance resources designed for store distribution (e.g., Microsoft Store) are documented in the installer and in the "MS-Store-ADA-v8.9-FINAL-EN.pdf" file included in the package.
   - Optional Pomodoro module: if the Software distribution includes the integrated Pomodoro module and the executable detects it at runtime, an additional local module may become available for focus/break cycles, alarm settings, and local task exchange between Eisenhower planning and Pomodoro execution.
   - Any task data shared between the main organizer and the integrated Pomodoro module is processed locally within the same installation/runtime context. Unless a separate written agreement states otherwise, the same general usage, restriction, privacy, warranty, and liability limitations of this License apply to that optional module module as part of the Software.
   - Optional Feynman module: if the Software distribution includes the integrated Feynman module and the executable detects it at runtime, an additional local module may become available for study-concept organization, simplified explanations, knowledge-gap tracking, and reviews, with the ability to link support files and integrate tasks with the main organizer.
   - Concepts, explanations, and reviews recorded in Feynman are handled locally within the same installation/runtime context. The user is responsible for the content and for rights over linked files.
   - Optional Mind Map module: if the Software distribution includes the integrated Mind Map module and the executable detects it at runtime, an additional local module may become available for concept maps, notes, linked files, JSON save/load, local autosave, PNG export, layout modes, and document import for assisted generation through local processing/AI when the required resources are present.
   - Mind map content, imported documents, linked-file paths, preferences, and results generated by the Mind Map module remain under the user's control and are processed locally, except for any external action performed by the user outside the Software.
   - Outputs generated by processing/AI are auxiliary and must be reviewed by the user. The user is responsible for rights over imported documents and for the use of generated maps.
   - Optional Audiobook module: if the Software distribution includes the integrated Audiobook module and the executable detects it at runtime, an additional module may become available for reading text and PDFs aloud, search, PDF navigation, voice/font adjustments, assisted reading, focus ruler, and temporary audio generation.
   - Texts, PDFs, voice/font preferences, and temporary audio files are handled locally, except when the user voluntarily activates a voice based on an external service, such as Edge TTS. In that case, the text selected for reading may be transmitted to the voice service to synthesize audio, subject to that service's terms and availability.
   - The user is responsible for respecting copyrights in texts, PDFs, and other materials read or converted to audio by the module.

- Integrated Gantt & BIM 4D module: advanced scheduling features, Gantt charts, critical path calculations (CPM), milestones, baselines, and 4D construction simulation, with strictly local schedule storage.
   - Integrated Assessment Agenda module: chronological planning, assessment registration, deadlines, and grades, persisted in a local SQLite database within the user profile.
   - Integrated Local Qwen AI Model module: AI inference and concept structuring executed 100% locally on the user's hardware via llama.cpp, with no prompts or data sent to external servers.
