Description:
The Mind Map module adds a visual module for creating concept maps, notes, and relationships between ideas. It works as a native module integrated into the main application.

Main features:
- Creation, editing, movement, and connection of nodes.
- Notes, colors, linked files, and layout modes.
- Saving/loading maps as JSON.
- Local autosave and PNG export.
- Import of user-selected documents for generation assisted by local processing when resources are available.

Data and connectivity:
- The module operates locally and does not send maps or documents to the developer.
- Local AI resources, when present, use local files and models.
- Purchase, license, and access confirmation are processed by the Microsoft Store.
