Aviso de Licenças e Atribuições de Software de Terceiros

Este documento descreve os principais componentes de terceiros associados à distribuição atual do EISENHOWER ORGANIZER. A aplicação é implementada nativamente em C++23 com Qt 6.12.0.

Componente principal de terceiros na distribuição atual
- Qt 6
  - Uso: base de interface gráfica, internacionalização, recursos visuais e componentes de execução necessários para o aplicativo Windows.
  - Forma de distribuição: bibliotecas dinâmicas, plugins de plataforma e arquivos auxiliares entregues junto com o executável.
  - Licenciamento: conforme os termos aplicáveis da distribuição Qt utilizada no processo de compilação e empacotamento, incluindo os requisitos da LGPL quando aplicáveis.
  - Referências oficiais:
    https://www.qt.io/
    https://doc.qt.io/
    https://www.gnu.org/licenses/lgpl-3.0.html
Componentes de runtime adicionais e materiais de licença
- FFmpeg: o Qt Multimedia pode implantar bibliotecas de runtime FFmpeg (avcodec, avformat, avutil, swresample, swscale e o módulo multimídia FFmpeg do Qt). A build FFmpeg fornecida pelo Qt observada informa LGPL versão 2.1 ou posterior, usa bibliotecas compartilhadas e não informa --enable-gpl nem --enable-nonfree. Consulte LICENSES/FFmpeg_LGPL_BUILD_CONFIGURATION.txt.
- Runtime MinGW: builds MinGW podem incluir libgcc, libstdc++, libwinpthread ou arquivos de runtime relacionados. Consulte os textos GPLv3, GCC Runtime Library Exception e MinGW-w64 runtime em LICENSES.
- Runtime MSVC/Microsoft: builds MSVC podem incluir arquivos Microsoft VC/UCRT/DirectX sujeitos aos termos redistribuíveis da Microsoft. Consulte LICENSES/Microsoft Redistributable Runtime Notice.txt.
- SQLite/SQL: arquivos Qt SQL/qsqlite e componentes relacionados ao SQLite permanecem sujeitos aos avisos aplicáveis do Qt e do SQLite. Consulte LICENSES/SQLite Blessing.txt.
- Runtime local de IA do Mapa Mental: quando o módulo Mapa Mental for entregue com llama.cpp/GGML, arquivos CPU/Vulkan ou libomp, consulte LICENSES/llama.cpp MIT License.txt e LICENSES/LLVM OpenMP License.txt.
- DirectX/DXC: se dxcompiler.dll, dxil.dll, D3DCompiler_47.dll ou arquivos equivalentes forem entregues, consulte LICENSES/DirectXShaderCompiler License.txt e os termos de redistribuição Microsoft aplicáveis.

Observações sobre conformidade e substituição de bibliotecas
- A distribuição padrão do aplicativo mantém os componentes Qt de execução em arquivos separados, compatíveis com o modelo usual de distribuição dinâmica.
- Quando exigido pela licença aplicável, o código-fonte correspondente da tecnologia Qt pode ser obtido pelos canais oficiais do próprio projeto Qt.
- Caso a política de conformidade da organização usuária exija revisão, substituição ou auditoria desses componentes, recomenda-se utilizar versões compatíveis obtidas pelas fontes oficiais e realizar testes próprios antes da implantação.

Escopo atual deste aviso
- Este aviso se aplica ao aplicativo principal distribuído em formato executável nativo para Windows.
- Ferramentas auxiliares atualmente entregues com o projeto também foram migradas para C++ e seguem o mesmo princípio de distribuição por executáveis nativos.
- Componentes históricos do repositório que tenham existido em versões anteriores não devem ser interpretados como parte obrigatória da distribuição padrão atual.

- Quando o módulo integrado Pomodoro estiver embarcado na distribuição oficial e for detectado pela aplicação, este aviso também deverá ser interpretado como aplicável a esse módulo nativo opcional e a quaisquer componentes de terceiros, arquivos de runtime ou obrigações de licença especificamente entregues com ele no mesmo pacote.

- Quando o módulo integrado Feynman estiver embarcado na distribuição oficial e for detectado pela aplicação, este aviso também deverá ser interpretado como aplicável a esse módulo nativo opcional e a quaisquer componentes de terceiros, arquivos de runtime ou obrigações de licença especificamente entregues com ele no mesmo pacote.

- Quando o módulo integrado Mapa Mental estiver embarcado na distribuição oficial e for detectado pela aplicação, este aviso também deverá ser interpretado como aplicável a esse módulo nativo opcional, às suas traduções, aos seus fluxos de importação/exportação e a quaisquer componentes de terceiros, arquivos de runtime, modelos locais ou obrigações de licença especificamente entregues com ele no mesmo pacote.
- O módulo Mapa Mental pode utilizar módulos do Qt 6, recursos de SQL/SQLite, leitura de arquivos estruturados, processamento local de documentos e, quando fornecidos ou configurados, runtimes locais de IA como llama.cpp/GGML, com variantes CPU/Vulkan e arquivos auxiliares relacionados.
- Componentes de IA local, modelos, runtimes, drivers e bibliotecas distribuídos com o módulo devem ser acompanhados de suas próprias licenças e avisos. O usuário ou distribuidor deve validar esses textos antes de redistribuição ou implantação corporativa.

- Quando o módulo integrado Audiolivro estiver embarcado na distribuição oficial e for detectado pela aplicação, este aviso também deverá ser interpretado como aplicável a esse módulo nativo opcional, às suas traduções, aos seus recursos de leitura acessível e a quaisquer componentes de terceiros, arquivos de runtime ou obrigações de licença especificamente entregues com ele no mesmo pacote.
- O módulo Audiolivro pode utilizar módulos do Qt 6 relacionados a PDF, multimídia, rede, WebSocket, texto, interface e reprodução de áudio. Esses componentes continuam sujeitos aos termos aplicáveis da distribuição Qt utilizada.
- Recursos de voz baseados em Edge TTS ou serviço equivalente não representam telemetria automática do aplicativo, mas podem depender de serviço externo acionado pelo usuário para sintetizar áudio. O uso desses serviços permanece sujeito aos termos, políticas, disponibilidade e eventuais limitações do respectivo provedor.
- Quando o módulo integrado Gantt & BIM 4D estiver presente, este aviso aplica-se aos seus componentes de cálculo de caminho crítico, recursos gráficos e manipulação de arquivos CSV.
- Quando o módulo integrado Agenda de Avaliações estiver presente, este aviso aplica-se aos seus componentes de banco de dados SQLite e recursos de interface.
- Quando o módulo integrado Modelo Qwen estiver presente, este aviso aplica-se ao motor de inferência llama.cpp (licença MIT) e aos modelos da família Qwen 2.5 (licença Qwen / Apache 2.0).

Declaração sobre transmissão de dados e privacidade
- O executável padrão não envia telemetria automática a servidores externos.
- Os dados do usuário, como tarefas e arquivos exportados, permanecem armazenados localmente sob controle do próprio usuário.
- Para detalhes adicionais, consulte a Política de Privacidade incluída na distribuição.
- Quando o módulo integrado Feynman estiver ativo, conceitos, explicações, revisões e caminhos de arquivos vinculados permanecem no ambiente local do usuário, salvo ação externa realizada pelo próprio usuário.
- Quando o módulo integrado Mapa Mental estiver ativo, documentos escolhidos pelo usuário para importação são lidos para extração/análise local e mapas/autosalvamentos permanecem no ambiente local do usuário, salvo ação externa realizada pelo próprio usuário.
- Quando o módulo integrado Audiolivro estiver ativo, textos e PDFs permanecem locais durante edição/leitura; entretanto, ao selecionar uma voz baseada em serviço externo como Edge TTS e iniciar a leitura, o texto selecionado poderá ser transmitido ao provedor de voz para geração do áudio.
