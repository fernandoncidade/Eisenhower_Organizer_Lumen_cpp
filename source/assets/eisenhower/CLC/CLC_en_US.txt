1.1 The purpose of this Agreement is to grant, from the LICENSOR to the LICENSEE, a license to use the software named "EISENHOWER ORGANIZER" ("Software"), according to the licensing modality purchased.
1.2 The Software is an application for organizing and managing tasks based on the Eisenhower Matrix (Important × Urgent), featuring creation, prioritization, marking as completed, local persistence (tasks.json), export/import to XLSX and PDF, multilingual interface, offline operation of the main application on Windows, and support for optional modules detected at runtime. Commercial installation is provided via installer/executable; the end LICENSEE does not need to install development dependencies.

1.3 When the commercial distribution includes the integrated Pomodoro module and the main executable detects and enables that module, the module shall be treated only as an accessory local module integrated into EISENHOWER ORGANIZER, and not as an independent software product unless expressly stated in a separate written addendum.

1.5 When the commercial distribution includes the integrated Feynman module and the main executable detects and enables that module, the module shall be treated as an accessory local module integrated into EISENHOWER ORGANIZER, and not as an independent software product unless expressly stated in a separate written addendum.
1.6 In that scenario, the integrated module offers study-concept organization, simplified explanations, knowledge-gap tracking, and reviews, with the ability to link support files and integrate tasks with the main organizer, subject to the same general licensing, restriction, liability, and support framework applicable to the Software, except where a specific commercial addendum provides otherwise.

1.7 When the commercial distribution includes the integrated Mind Map module and the main executable detects and enables that module, the module shall be treated as an accessory local module integrated into EISENHOWER ORGANIZER, and not as an independent software product unless expressly stated in a separate written addendum.
1.8 In that scenario, the integrated module offers creation and editing of visual concept maps, linked files, notes, JSON save/load, local autosave, PNG export, layout modes, and document import for assisted map generation when local processing/AI resources are available.

1.9 When the commercial distribution includes the integrated Audiobook module and the main executable detects and enables that module, the integrated module operates as a native component of integrated into EISENHOWER ORGANIZER, and not as an independent software product unless expressly stated in a separate written addendum.
1.10 In that scenario, the integrated module offers accessible text and PDF reading, playback controls, voice/font adjustments, text and PDF search, assisted reading, focus ruler, local preferences, and temporary audio generation. Voice features depending on Edge TTS or an equivalent service may require a user-initiated network connection and third-party service availability.
