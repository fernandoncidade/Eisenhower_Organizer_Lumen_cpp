Module: Local Qwen AI Model

Description:
The integrated Local Qwen AI Model module adds advanced natural language processing, text analysis, conceptual structuring, and hierarchy generation capabilities to EISENHOWER ORGANIZER, running 100% locally and offline on the user's computer.

Key features:
- High-performance local inference using quantized Qwen2.5 models (qwen2.5-3b-instruct-q4_k_m.gguf) powered by the llama.cpp engine.
- Automated generation of concept hierarchies and topic trees for the Mind Map module.
- Semantic analysis and structured summaries of documents and study notes.
- Complete offline capability: works without internet connection and without external third-party API dependencies.
- Multi-threaded CPU execution with local graphics acceleration support where available.

Data and privacy:
- Absolute privacy by design: analyzed text, prompts, and completions never leave the user's machine.
- No information is sent to third-party cloud servers.
- AI model weights reside locally within the application data structure.
